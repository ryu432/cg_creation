# Plano 企画書

> 最終更新: 2026-10-22 / ステータス: Phase 1 開発中

---

## 1. 概要

| 項目 | 内容 |
|---|---|
| アプリ名 | **Plano**（Plan + 軽やかさ） |
| ジャンル | AIアシスト型タスク管理アプリ |
| プラットフォーム | スマホアプリ（iOS / Android） |
| 対象 | まずは自分用 → 将来的に一般公開 |
| 一言で | **「今日やること」をAIが理由つきで提案してくれるタスク管理** |

### コンセプト

> 頭の中のことを雑に書き出すだけ。
> 毎朝、AIが「今日はこれをやろう」と理由つきで段取りを組んでくれる。

### 基本方針

- **主役はユーザー、AIは提案するだけ。** AIが勝手に確定・削除・変更することはしない。
- **提案には必ず理由を表示する。** 納得して使えるようにし、ズレていたら気づけるようにする。
- **AIがなくても使える。** AIが止まっても、普通のタスク管理アプリとして動く。
- **入力の手間を最小にする。** 自然な言葉で書けば、期限・見積もり時間などは自動で埋める。

---

## 2. 解決したい課題

| 課題 | Planoでの解決 |
|---|---|
| タスクが多すぎて、何から手をつければいいか分からない | 毎朝AIが3〜5個に絞って提案する |
| 予定を詰め込みすぎて、結局終わらない | 「今日使える時間」と「体力」に合わせて量を調整する |
| 面倒なタスクをずっと先送りしてしまう | 延期回数を記録し、分解や「最初の一歩」を提案する |
| タスクの入力（期限・分類など）が面倒 | 自然な言葉の入力から自動で項目を埋める |

---

## 3. 主要機能

### 3.1 ⭐ 今日のプラン提案（主役機能）

#### 1日の流れ

```
🌅 朝   7:30に通知「今日のプランができました」（時刻は変更可能）
        → 「今日使える時間」と「体力」を選ぶ
        → AIが3〜5個のタスクを理由つきで提案
        → ✓採用 / ↔入れ替え / ✕外す で調整して確定

☀️ 日中  「今日」画面で一つずつ完了していく

🌙 夜   やり残しを「明日に回す / 期限を変える / 分解する」からワンタップで選ぶ
```

#### AIが判断に使う情報

| 情報 | 入力方法 |
|---|---|
| 期限（近い・過ぎている） | タスクごとに設定 |
| 優先度 | タスクごとに設定（任意） |
| 見積もり時間 | AIが推定 → ユーザーが修正できる |
| 今日使える時間 | 朝に選ぶ（30分 / 1時間 / 2時間 / 半日 / 1日 の5段階） |
| 体力・気分 | 朝に選ぶ（😫 低い / 🙂 普通 / 💪 高い） |
| 延期した回数 | アプリが自動で記録 |

#### 表示イメージ

```
今日のプラン（使える時間: 約2時間 / 体力: 🙂）

1. 📄 企画書の構成を決める     45分
   └ 金曜締切。今日やらないと間に合いません
2. 📞 歯医者に電話する          5分
   └ 3回延期されています。すぐ終わります
3. 🛒 洗剤を買う               15分
   └ 帰り道についでにできます

 [このプランで始める]   [作り直す]
```

### 3.2 自然言語でタスク追加

- 例: 「金曜までに資料作る、2時間くらい」
  → タイトル: 資料作成 / 期限: 金曜 / 見積もり: 2時間
- 確定前にプレビューを表示し、ユーザーが修正できる。

### 3.3 タスク分解

- 大きなタスクをサブタスクに分ける提案。
- 例: 「引っ越し準備」→ 業者の見積もり / 住所変更 / 荷造り / 不用品の処分
- 何度も延期されているタスクには、自動で分解を提案する。

### 3.4 基本のタスク管理（AIなしでも動く部分）

- タスクの追加・編集・削除・完了
- 期限・優先度・見積もり時間
- プロジェクト（分類）
- 一覧表示・並び替え

## 5. 技術構成

```
アプリ      : Expo (React Native) + TypeScript
DB・認証    : Supabase（PostgreSQL + ログイン + 端末間の同期）
AI呼び出し  : Supabase Edge Functions（サーバー側）→ Claude API
通知        : Expo Notifications（朝のプラン通知）
ビルド・配信 : EAS Build / EAS Submit
```

### この構成にした理由

- **iOS・Android を1つのコードで作れる**
- **実機ですぐ確認できる**（Expo Go アプリでQRコードを読むだけ。Macがなくても開発できる）
- **TypeScript は情報量が最も多い言語の一つ** で、初学者でも調べやすい
- **ログイン・DB・サーバー処理を Supabase にまとめられる** ので、一人でも運用できる

### AI利用の方針

- **APIキーはサーバー側（Edge Functions）だけに置く。** アプリから直接 AI の API を呼ばない。
- **処理の重さでモデルを使い分ける。** 入力の解析などの軽い処理は軽量モデル、プラン提案や分解は上位モデル。
- **AIには構造化された形式（JSON）で結果を返させる。** アプリ側で扱いやすく、表示が崩れない。
- **ユーザーごとに1日の利用回数の上限を設ける。** コストの急増を防ぐ。

#### プランの作り方を切り替える

`mobile/app.json` の `expo.extra.planner` で切り替える。

| 値 | 方式 | 費用 | 必要な準備 |
|---|---|---|---|
| `"local"`（今の設定） | 端末内のルール（`mobile/src/lib/planners/local.ts`） | 無料 | なし |
| `"ai"` | Claude（`mobile/src/lib/planners/ai.ts` → `supabase/functions/plan`） | 1回 数円程度（モデルによる） | Anthropic API キー、Supabase、`planApiUrl` の設定 |

AI に切り替えるときの手順:
1. Anthropic Console で API キーを作り、月の利用上限を設定する
2. Supabase のプロジェクトを作り、Edge Functions の Secrets に `ANTHROPIC_API_KEY` を登録する
3. GitHub の Secrets に `SUPABASE_ACCESS_TOKEN` を登録し、`.github/workflows/supabase-functions.yml` の `SUPABASE_PROJECT_REF` に Project ID を入れる
4. `mobile/app.json` の `expo.extra` を `"planner": "ai"`、`"planApiUrl": "https://<Project ID>.supabase.co/functions/v1/plan"` にする

> 注意：ログイン機能ができるまで、AI のプラン提案 API は誰でも呼べる状態になる。
> 利用上限を必ず設定しておく。ログイン後は JWT 検証とユーザーごとの回数制限に切り替える。
> 費用を抑えたいときは `supabase/functions/plan/index.ts` のモデルを軽量なもの（Haiku）にする。

## 8. 公開に向けて考えること

### 収益化（案）

| プラン | 内容 |
|---|---|
| 無料 | 基本機能は無制限。AIプラン提案は1日3回まで |
| 有料（月額） | AI機能を無制限、振り返りレポート、カレンダー連携 |

### プライバシー

- タスクの内容は個人的な情報なので、**AIに送るデータの範囲と扱いをプライバシーポリシーに明記する。**
- AIに送るのは提案に必要な最低限の情報だけにする。

### 公開に必要なもの

- Apple Developer Program への登録（年額）
- Google Play Console への登録（初回のみ）
- プライバシーポリシーと利用規約
- ストア用のスクリーンショット・説明文
- 「Plano」という名前がストアや商標で使えるかの確認

## 9. 決定事項

| 項目 | 決定内容 | 理由 |
|---|---|---|
| 「今日使える時間」の選択肢 | **5段階**: 30分 / 1時間 / 2時間 / 半日 / 1日 | 迷わず選べて、提案量の調整にも十分な細かさ |
| 朝の通知のデフォルト時刻 | **7:30**（設定で変更可能） | 通勤・通学前にプランを確認できる |
| ログイン方法 | **Apple / Google** | パスワード不要でワンタップ。iOSで他社ログインを出す場合はAppleログインも必須 |
| AIプラン提案の上限（無料プラン） | **1日3回**（朝の提案＋作り直し2回） | 毎日使うには十分で、コストも見積もりやすい |
| デザインの雰囲気 | **やさしい・落ち着き** | 余白多め、角丸、彩度低め。朝に開いても焦らされない |
| メインカラー | **朝焼けオレンジ** | 朝のプランから始まるアプリに合う、暖かく前向きな色 |
| ダークモード | **端末の設定に合わせる**（最初から対応） | あとから入れるより楽 |
