## 1. Plano ってどんなアプリ？

**「今日やること」を、期限と使える時間から段取りしてくれるタスク管理アプリ**です。

やることを思いつくままに書き出しておくと、毎朝「今日はこれとこれをやろう」と**理由つきで**提案してくれます。夜には、やり残したタスクを「明日に回す」などワンタップで片付けられます。

### こんな人向け
- やることが多すぎて、何から手をつければいいかわからない
- つい予定を詰め込みすぎて、結局終わらない
- 面倒なタスクを先送りしがち

### 1日の流れ
```
☀️ 朝   「今日のプランを作る」→ 使える時間と体力を選ぶ → 今日やるタスクが理由つきで並ぶ
🏃 日中  終わったタスクの ○ をタップして完了
🌙 夜   振り返りで、やり残しを「明日に回す」「期限を変える」などに振り分ける
```

### 大事にしていること
- **決めるのは自分**：プランは提案だけ。外したいものは外してから確定する
- **理由が見える**：「明日が期限です」「3回先送りしています」など、なぜそれを選んだかを必ず表示する
- **詰め込まない**：使える時間と体力に合わせて量を調整する。大きいタスクは「30分だけ」に区切る
- **無料・オフラインで動く**：今のプラン作成はスマホの中のルールで行う（AI は使っていない。将来切り替えられる作り）

## 2. 画面

| 画面 | できること |
|---|---|
| **今日** | 今日の日付と完了数、今日のプラン、今日やるタスク。右下の＋で追加 |
| **すべて** | 全タスク（期限が近い順）。プロジェクトで絞り込み、完了したタスクの表示切り替え |
| **設定** | プランの設定、通知、プロジェクト、データ（書き出し・読み込み・削除）、ヘルプ |
| タスクの追加・編集 | 名前（必須）、期限、見積もり時間、プロジェクト、今日やる、区切ってよいか |
| 今日のプラン | 使える時間・体力を選んで提案 → 外したいものを外して確定 |
| 振り返り | やり残しを、明日に回す／期限を変える／今日やるから外す／完了にする |
| チュートリアル | 初回起動時に自動で表示。右上の ？ からいつでも見直せる |

画面右上の **？** で使い方、**✉** でお問い合わせ（準備中）。

## 3. 機能

### 3.1 タスク
- **追加**：右下の＋ボタンから。「今日」画面から追加すると「今日やる」がはじめからオン。「すべて」でプロジェクトを絞り込み中なら、そのプロジェクトがはじめから選ばれる
- **項目**

  | 項目 | 内容 |
  |---|---|
  | 名前 | 必須 |
  | 期限 | なし／今日／明日／1週間後／カレンダーで任意の日 |
  | 見積もり時間 | なし／15分／30分／1時間／2時間／半日（任意） |
  | プロジェクト | 色分けしたグループ（任意） |
  | 今日やる | 今日の画面に出す |
  | 区切って進めてもよい | 大きいタスクを「30分だけ」のように進めてよいか（見積もりが大きいときだけ表示） |

- **確定と破棄**：「登録」「保存」を押したときだけ反映。戻ると破棄（変更があれば確認）
- **完了**：一覧の ○ をタップ（もう一度で未完了に戻る）
- **まとめて操作**：タスクを長押しで選択モード → まとめて完了／プロジェクトへ移動／削除。左上の ← で解除

### 3.2 プロジェクト
- 名前と色（6色）で作成。「すべて」画面で絞り込める
- プロジェクトを削除しても、中のタスクは「プロジェクトなし」として残る

### 3.3 今日のプラン（自動プラン）
「今日使える時間」（30分／1時間／2時間／半日／1日）と「体力・気分」（😫 低い／🙂 普通／💪 高い）を選ぶと、次のルールで選ぶ。

**選ぶ順番**

| 順位 | 対象 | 表示する理由の例 |
|---|---|---|
| 1 | 期限切れ | 期限が2日過ぎています |
| 2 | 今日が期限 | 今日が期限です |
| 3 | 「今日やる」に入れたもの（前の日のやり残しを含む） | 昨日やる予定だったタスクです |
| 4 | 明日が期限 | 明日が期限です。今日進めておくと安心です |
| 5 | 1週間以内が期限 | 10/30(金)が期限です |
| 6 | その他 | 22日前から残っています |

- 同じ順位の中では、期限が早い順 → 古い順（体力が低い日は**短い順**を優先）
- 2回以上先送りしているものは「2回先送りしています。少しだけでも手をつけましょう」と知らせる

**量の調整**

| 体力 | 最大件数 | 使える時間のうち埋める割合 | 1件の長さ |
|---|---|---|---|
| 😫 低い | 3件 | 75% | 1時間まで（超えるものは区切る） |
| 🙂 普通 | 5件 | 100% | 制限なし |
| 💪 高い | 6件 | 100% | 制限なし |

- 見積もり時間がないタスクは30分として計算（「（仮）」と表示）
- 期限切れ・今日が期限のものは、時間を超えても入れる（「少し多めです」と表示）

**大きいタスクの区切り**
- そのままでは今日の時間に入らない大きいタスクは「**30分だけ（全体 約4時間）**」のように区切って入れる
- 区切らないもの：期限切れ・今日が期限のもの／見積もりがないもの／小さいもの／タスクごとに「区切らない」にしたもの
- 区切るのは1日2件まで
- 設定でオン・オフ、対象（見積もり1時間以上／2時間以上）、1回の時間（30分／1時間）を変えられる

### 3.4 夜の振り返り
- 「今日」画面に 🌙 のカードが出る
  - 18時以降で今日のタスクが残っているとき
  - 前の日の「今日やる」が残っているとき
- やり残しごとに：**明日に回す**／**期限を変える**（カレンダー）／**今日やるから外す**／**完了にする**。残りをまとめて明日に回すこともできる
- 「明日に回す」の回数を記録し、3回以上で「小さく分けるか、見積もりを見直しましょう」と表示

### 3.5 通知
- 朝のプラン（初期 7:30）と夜の振り返り（初期 21:00）。設定でオン・オフと時刻（5分刻み）を変えられる
- 通知をタップすると、プラン画面／振り返り画面が開く
- スマホの中で出すローカル通知（サーバーは使わない）

### 3.6 データ
- **すべてスマホの中に保存**（アカウント・サーバーなし）
- **書き出し**：設定 → データ → 書き出す。スマホの共有機能でメモや LINE などに送れる（バックアップ・機種変更用）
- **読み込み**：書き出した文字を貼り付けると、中身（タスク◯件など）を確認してから読み込む。今のデータは置き換わる
- 完了したタスクの一括削除、全データの削除

## 4. しくみ（技術）

| 項目 | 内容 |
|---|---|
| アプリ | Expo（React Native）＋ TypeScript。iOS・Android 共通のコード |
| 画面遷移 | Expo Router |
| 保存 | 端末内（AsyncStorage） |
| 配布 | EAS Build で Android の APK を作り、リンクからインストール |
| 更新 | EAS Update。修正はプッシュすると自動で配信され、アプリを開き直すと反映 |
| 自動化 | GitHub Actions（更新の配信・アプリのビルド） |
| AI（準備のみ） | Claude API を Supabase 経由で呼ぶ仕組みがある。設定を `"ai"` に変えると AI のプラン提案に切り替わる（現在はオフ） |
