# Plano Web 版 構想

> 作成日：2026-10-24　状態：W3 完了（公開中：https://plano.expo.app）

## 1. 目的

- **iPhone の人にも配れるようにする**（App Store の有料登録なしで、Safari から使える）
- **パソコンでも使えるようにする**（タスクの入力・整理は大きい画面のほうが楽）
- 機能は Android 版と同じ（今日のプラン、ルーティン、振り返り、プロジェクト、詳細欄など）

## 2. 基本方針：同じコードから作る

Web 版を別に作り直さず、今の `mobile/` のコードをそのまま Web にも書き出す（Expo は Web にも対応している）。

- 良いところ
  - 機能追加は1回で Android 版と Web 版の両方に入る（ルーティンのような新機能もそのまま）
  - 今の画面・計算（自動プラン・ルーティン）を全部使い回せる
  - これまでのテストでもブラウザ版で動作確認しており、ほぼ動くことがわかっている
- 気をつけること
  - スマホにしかない機能（通知・共有・長押しなど）は、Web 用の代わりを用意する
  - Web だけの不具合が Android 版に影響しないよう、Web 用の処理は分けて書く

## 3. Web で足りないもの・対応

| 項目 | 今の状態 | Web での対応 |
|---|---|---|
| 確認ダイアログ | スマホは Alert。Web はブラウザの confirm（見た目が悪く、「この回だけ／ルーティンごと」のような選択肢を出せない） | アプリ内のダイアログ部品を作り、スマホ・Web 共通で使う |
| データの書き出し | スマホの共有機能 | ファイルとして保存（ダウンロード）＋クリップボードにコピー |
| データの読み込み | 貼り付け | 貼り付け＋ファイルを選ぶ |
| 長押しで選択 | スマホ向け | スマホのブラウザは長押しのまま。パソコンは右上に「選択」ボタン |
| 画面の幅 | スマホ幅前提 | パソコンでは中央に最大 600px 程度で表示（横に間延びしない） |
| 朝晩の通知 | スマホのローカル通知 | 最初は無し。同期ができたあとに Web Push で対応（5章） |
| ホーム画面に追加 | ― | PWA（アイコン・全画面表示・オフラインで開ける） |

## 4. データの保存（いちばん大事なところ）

### 最初はブラウザの中に保存
今のスマホ版と同じく、ログインなしでブラウザの中（localStorage）に保存する。

⚠️ 注意点
- **スマホのアプリと Web 版のデータは別々**。行き来はバックアップの書き出し・読み込みで行う
- **iPhone の Safari は、7日間開かなかったサイトのデータを消すことがある**。
  「ホーム画面に追加」して使えば消えないので、iPhone では追加を強くすすめる（初回に案内を出す）
- ブラウザの「履歴・データを削除」でも消える → 定期的な書き出しを促す

### 次に同期（ログイン）
Android と Web で同じデータを使うには、ログインと同期が必要。企画書の Phase 1 にある「ログイン（Apple / Google）と同期（Supabase）」を、Web 版をきっかけに進める。

- 同期ができれば、スマホで追加したタスクをパソコンで整理する、といった使い方ができる
- データ消失の心配もなくなる
- ただし規模は大きい（ログイン画面、サーバー、オフライン時の扱い、データの引っ越し）。Web 版の公開とは分けて進める

## 5. 通知（後回し）

Web の通知は、アプリが閉じていても届けるにはサーバーから送る仕組み（Web Push）が必要。
iPhone は「ホーム画面に追加」したときだけ通知を受け取れる（iOS 16.4 以降）。
→ 同期（サーバー）ができてから、朝晩の通知を Web Push で送る。それまでは「今日」画面を開いたときのカード（振り返りなど）で代わりにする。

## 6. 公開先

| 候補 | 費用 | 特徴 |
|---|---|---|
| **EAS Hosting（おすすめ）** | 無料枠あり | Expo の公開サービス。今の EAS Update と同じ Expo のアカウント・GitHub の設定（EXPO_TOKEN）をそのまま使える。URL は `https://plano.expo.app` のような形 |
| GitHub Pages | 無料 | リポジトリが公開なので使える。URL は `https://ryu432.github.io/cg_creation/`。ページの直リンク（タスク編集画面など）に一工夫いる |
| Vercel / Cloudflare Pages | 無料枠あり | 独自ドメインを付けやすい。アカウント作成が別に必要 |

公開の流れ（EAS Update と同じく自動）：
1. `mobile/` を変更してプッシュ
2. GitHub Actions が Web 版を書き出して公開
3. ブラウザで開き直すと新しい版になる

## 7. 進め方

| 段階 | 内容 | できること |
|---|---|---|
| **W1 公開** | Web 用の部品を追加、自動公開の仕組み、パソコン向けの幅 | URL を開けば今の機能がブラウザで使える |
| **W2 Web らしく** | アプリ内ダイアログ、ファイルで書き出し・読み込み、パソコンの「選択」ボタン、タブの題名、キーボード操作（Enter で登録など） | 確認や選択肢が見やすくなり、パソコンでも操作しやすい |
| **W3 ホーム画面アプリ化（PWA）** | アイコン・全画面表示・オフライン対応、iPhone 向け「ホーム画面に追加」の案内、データを消されにくくする設定 | iPhone でアプリのように使える。データも消えにくい |
| **W4 同期** | ログイン（Google / Apple）、Supabase でデータを共有 | スマホとパソコンで同じタスク |
| **W5 通知** | Web Push で朝晩のお知らせ | Web でも通知 |

W1〜W3 は今の仕組みの延長で、追加の費用なしでできる。W4 から先はサーバーが必要（Supabase の無料枠で始められる見込み）。

## 8. しくみのメモ

- Web 用の設定（`platforms` に web、`web.output: single`）は `mobile/app.config.js` で **`PLANO_WEB=1` のときだけ** 足す。
  `app.json` を変えると Android アプリの版（runtimeVersion）が変わり、入っているアプリに更新が届かなくなるため
- Web の書き出しは `PLANO_WEB=1 EXPO_NO_WEB_SETUP=1 npx expo export --platform web`
- パソコンでは最大 640px の幅で中央に表示（`mobile/src/app/_layout.tsx` の WebFrame）
- 確認ダイアログは `mobile/src/lib/confirm.ts` の confirm / choose / notify を使う。スマホは Alert、Web はアプリ内のダイアログ（`DialogHost`）。`Alert.alert` を直接使うと Web では何も出ないので使わない
- Web の書き出しは「ファイルに保存／コピー」、読み込みは「ファイルを選ぶ／貼り付け」（`mobile/src/lib/webFiles.ts`）
- ホーム画面に追加（PWA）：`mobile/public/` の `index.html`（Web のページの元）・`manifest.json`・`icons/`・`sw.js`
  - `sw.js`（サービスワーカー）は公開のたびに全ファイルを保存し直し、電波がなくても開けるようにする。ページはネット優先なので、更新は次に開いたときに届く
  - 公開時に `scripts/web-precache.js` が保存するファイルの一覧（`precache.json`）を作り、`sw.js` に版を書き込む
  - iPhone の Safari ではホーム画面に追加していないと「今日」画面に案内を出す（× で閉じられる。設定の「ホーム画面に追加」からいつでも見られる）。Android の Chrome などはボタンで追加できる
  - ブラウザにデータを消さないよう頼む（`navigator.storage.persist`。Firefox は確認が出るので頼まない）
  - アイコンは「朝日とチェック」（アプリと共通。元の図形は SVG で描き、各サイズに書き出している）
- Web では右上の「選択」で選択モードに入れる。タスク名の欄で Enter を押すと登録・保存（変換中の Enter は除く）
